L14 — API Industrial & 17 Ferramentas MCP

O agente não "sabe" nada; ele consulta a API via ferramentas. Cada chamada retorna um Envelope com campo mode.

Modos de Envelope

ModeSignificado
completeDados íntegros, suficiente para decisão
partialDados incompletos, mas úteis
inconclusiveNão dá pra concluir (ruído, SNR baixo)
conflictDados conflitam (ex: baseline vs análise)
unavailableServiço fora do ar / não implementado

As 17 Ferramentas (agent/tools/)

  • Contexto: get_company, get_user, get_asset
  • Sinais: get_rms, get_spectrum, get_baseline, get_data_quality
  • Análises: get_analyses, get_analysis_detail
  • Ações (POST/PATCH): reprocess_analysis, request_specialist, request_retraining, update_asset_config, escalate_case

MCP Server

O servidor MCP expõe essas funções como tools para o LLM. O agente decide qual chamar; o MCP executa e devolve o envelope.
