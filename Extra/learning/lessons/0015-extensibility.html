L15 — Como Adicionar Novas Ferramentas e Ações

1. Nova Tool de Leitura (GET)

  1. Crie agent/tools/nova_tool.py com função async def fetch_nova(...) -> dict.
  2. Registre no agent/tools/__init__.py.
  3. Adicione caso em agent/graph/nodes.py no nó investigate (palavras-chave).
  4. Teste: make eval --split train.

2. Nova Ação de Impacto (POST/PATCH)

  1. Adicione endpoint na API Industrial (api/app/main.py).
  2. Crie tool em agent/tools/acao_nova.py.
  3. Atualize _extract_action() em nodes.py para detectar palavras-chave.
  4. Adicione URL em _build_action_url().
  5. Teste HITL na UI Streamlit.

3. Novo Nó no Grafo

Se precisar de lógica complexa entre investigate e decide:

  1. Crie função em nodes.py.
  2. Adicione nó no agent/graph/agent.py (grafo compilado).
  3. Atualize arestas/rotas condicionais.
