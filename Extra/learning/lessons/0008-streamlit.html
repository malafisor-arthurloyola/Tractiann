L8 — Streamlit: construindo a janela do agente

O agente funciona no terminal. Mas para apresentar, testar e receber confirmações humanas (HITL), precisamos de uma interface visual. O Streamlit é a escolha mais rápida.

Por que Streamlit?

  • Python puro — não precisa de HTML/CSS/JS separado.
  • Roda com um comando: streamlit run app.py.
  • Widgets interativos: botões, formulários, expanders.
  • Rápido para prototipar e demonstrar.

O que a interface vai ter

Blocos principais do app

  1. Seletor de ticket — lê cases.json, lista tickets em um dropdown.
  2. Botão "Executar" — roda o grafo com o ticket selecionado.
  3. Resultado — mostra quality_verdict, gaps, decisão, justificativa.
  4. Trace passo-a-passo — cada nó do grafo, com dados e timestamps.
  5. Confirmação HITL — se a decisão for act, mostra botões de confirmar/cancelar (usa interrupt()).

Exemplo de código (pseudocódigo)

import streamlit as st
from agent.graph.agent import agent_graph

st.title("Tractian Agent")

# Lista de tickets
cases = load_cases()
selected = st.selectbox("Ticket", cases, format_func=lambda c: f"{c['ticket_id']}: {c['message'][:50]}")

if st.button("Executar"):
    with st.spinner("Investigando..."):
        result = agent_graph.invoke(initial_state(selected))

    # Mostra resultado
    st.metric("Quality", result["quality_verdict"])
    st.metric("Decisão", result["decision"])

    # Gaps
    if result["data_gaps"]:
        st.warning(f"Lacunas: {result['data_gaps']}")

    # Justificativa
    st.info(result["decision_justification"])

    # Trace
    with st.expander("Trace completo"):
        for step in result["trace"]:
            st.json(step)

Para o HITL (confirmação)

O Streamlit pode receber o interrupt() do LangGraph e exibir botões de confirmação. Quando o humano clica "Confirmar", o grafo retoma de onde parou.

Dica: o Streamlit roda em localhost:8501 por padrão. Para HITL, você precisa de um checkpoint_saver (em memória ou Postgres) para persistir o estado durante a pausa.

Teste seu entendimento

Pergunta 1
Qual a diferença entre rodar o agente no terminal e rodar no Streamlit?
Resposta

No terminal, o agente roda e imprime o resultado — sem interação. No Streamlit, o usuário seleciona o ticket, clica pra executar, visualiza o trace, e confirma ações de impacto. É a mesma lógica, só com interface.

Pergunta 2
O agente decide "act" e o Streamlit mostra um botão de confirmação. O que acontece por baixo dos panos?
Resposta

O interrupt() pausa o grafo e salva o estado. O Streamlit exibe os botões e espera. Quando o humano clica "Confirmar", o estado é recuperado do checkpoint e o grafo retoma — executando a ação de impacto.
