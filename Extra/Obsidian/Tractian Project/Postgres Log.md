# Postgres Log

## O que é (planejado, futuro)
Banco **Postgres** para registrar **execuções do agente** — útil para metrificar sucesso
e progresso entre versões.

## Por que é bom
- Comparar versões do [[Grafo LangGraph]].
- Guardar trace completo de cada execução (pra avaliação).
- Base para [[Ferramentas e Stack]] (dashboard/metrics).

## Quando entrar
**Depois** do core (MCP + LangGraph) e do harness de avaliação. É um incremento, não
pré-requisito.

## Status
⏳ Adiado (pós-core).
