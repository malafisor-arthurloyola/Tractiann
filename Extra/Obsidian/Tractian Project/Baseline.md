# Baseline

## Definição
O "estado normal" **aprendido do próprio ativo** a partir de histórico sadio. **Não** é
norma ISO genérica.

## Ciclo de estado
`learning` (dados insuficientes) → `established` (confiável) → `invalidated`
(mudança física invalidou o histórico; exige reaprendizado).

## Importância
O **limiar de alarme de RMS deriva do baseline** (referência + tolerância). Se o baseline
não está `established`, desvios não são confiáveis → pode ser motivo de **escalar**.
